# Pain Hunter

Pain Hunter is an AI-powered tool designed to identify real user pain points from Reddit and other sources. It helps entrepreneurs and developers discover actionable insights to create solutions that address user needs.

## Features

- **AI-Driven Query Generation**: Generate niche-specific search queries using OpenAI's GPT model.
- **Web Search Integration**: Search Reddit for user complaints and frustrations.
- **Pain Analysis**: Extract and score pain points based on frequency, emotion, and monetizability.
- **Telegram Bot**: Interact with the tool via a Telegram bot to hunt pains, view saved pains, and get daily digests.
- **Database Integration**: Save and manage user data, pain points, and statistics.
- **Daily Digest**: Receive fresh pain points every morning for selected niches.
